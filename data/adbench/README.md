# ADBench-derived datasets

The `.npz` files in this directory are selected benchmark inputs obtained from
the official ADBench data release: <https://github.com/Minqi824/ADBench>.
Please cite Han et al., “ADBench: Anomaly Detection Benchmark,” NeurIPS 2022.

ADBench aggregates datasets from multiple upstream sources. This artifact does
not assign a blanket license to those underlying datasets; consult the ADBench
release and the original source for each dataset before reuse or redistribution.
The manuscript's frozen annotations and reported analyses can be evaluated
without downloading or rerunning inference on these files.
