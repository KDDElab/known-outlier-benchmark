# UCI Lymphography dataset

Repository: <https://archive.ics.uci.edu/dataset/63/lymphography>.
UCI lists this dataset under CC BY 4.0. Please cite M. Zwitter and M. Soklic,
“Lymphography,” UCI Machine Learning Repository, 1988,
<https://doi.org/10.24432/C54598>.
