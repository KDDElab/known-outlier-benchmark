PEPPOL-EN16931-R120

Message

Invoice line net amount MUST equal (Invoiced quantity * (Item net price/item price base quantity) + Sum of invoice line charge amount - sum of invoice line allowance amount

Context
cac:InvoiceLine | cac:CreditNoteLine
Test
u:slack($lineExtensionAmount, ($quantity * ($priceAmount div $baseQuantity)) + $chargesTotal - $allowancesTotal, 0.02)
Usage
/ ubl:Invoice / cac:InvoiceLine / cbc:LineExtensionAmount
/ ubl:CreditNote / cac:CreditNoteLine / cbc:LineExtensionAmount
